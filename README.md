# PolyCAD 0.0.1

Early Windows x64 CAD geometry preview. Free to use; no account, subscription, activation or telemetry.

[Download the installer](https://github.com/robertmartic/polycad/releases/latest).
Choose PolyCAD-0.0.1-setup.exe under Assets. Portable ZIP is also available.

This early release lets you inspect Line, Circle and Polyline scenes with cursor-centered zoom,
middle-button pan, grid, axes, light/dark themes and optional GPU display. Native .polycad drawings
can be opened read-only through Windows Open with or by passing a path to the application.

Drawing/editing tools, Save, Undo/Redo, snapping, dimensions, DXF and document recovery are not
implemented yet. The agreed 0.1.0 CAD workflow remains in development. This is not a production CAD editor.

Windows 10 build 19041 or newer / Windows 11, x64. Self-contained; no separate .NET installation.
F: Zoom Extents. G: grid. Escape: cancel pan. Mouse wheel: zoom at pointer. Middle-drag: pan.

About contains Overview, offline Changelog and Updates. Installed copies can download and verify
updates, with cancellation, retry, full/delta selection and rollback. Startup checks can be disabled.
Portable copies can check availability; use the conventional installer to enable automatic replacement.

Processing stays on your PC. Update checks contact the official public GitHub channel; drawings
are never uploaded. Downloads are verified with SHA-256 using official GitHub release digests.
Packages are not code-signed; these hashes are not an independent publisher signature.
